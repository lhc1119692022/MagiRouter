# 定制清单

本文件记录 Fork 相对上游的全部改动，用来替代「对着截图逐个页面比对」。
合并上游前后各看一次，就能知道哪些地方可能冲突、哪些地方需要重新确认。

生成依据：`git diff --name-status main...magirouter`

## 改动边界

- 只改前端 `web/`，没有改 Go 后端、数据库结构或接口协议。
- 新增依赖仅两个字体包：`@fontsource-variable/outfit`、`@fontsource-variable/jetbrains-mono`。
- 构建期由 `scripts/release.ps1` 临时写入 `VERSION`，构建后还原。
- 设计令牌集中在 `web/src/styles/magirouter.css` 与 `elevenlabs-spec.css`。
  页面的「样子」以这两个文件为准，不以截图为准。

## 合并上游时的检查点

1. `web/src/i18n/locales/*.json` 冲突 → 取并集，禁止删键。
2. `web/src/lib/constants.ts` → 上游可能调整默认站点名/logo，保留 MagiRouter 版本。
3. `web/src/hooks/use-sidebar-data.ts` → 上游新增模块时确认是否要一并显示。
4. `web/src/lib/nav-modules.ts` → 上游改动签名时，保留 `ignoreSectionFlag`。
5. `web/src/styles/magirouter.css` 里对上游 class 的覆盖 → 上游改样式后重新核对一遍。
6. 合并完必须重新跑 `.\scripts\release.ps1`，否则线上不会变化。
